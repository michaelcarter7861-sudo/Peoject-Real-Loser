# Project Real Loser RC1.17 — Authored Character Clips & PBR Texture Sets

## Included source assets

- Eight 512x512 seamless base-color texture maps: concrete, desert sand, olive uniform fabric, brushed steel, weapon steel, weathered wood, foliage and rubber.
- Matching tangent-space normal maps and metallic/AO/smoothness mask maps for those eight materials (24 maps total), plus concrete panel, desert camouflage and urban camouflage base-color atlases (27 PNGs total).
- `AuthoredCharacterAnimation.cs` attaches Unity's legacy Animation system to runtime-loaded character rigs and selects idle, walk, aim/fire and neutralized/takedown clips.
- `PRLAuthoredAnimationAndTexturePipeline.cs` generates five project-owned keyframed `.anim` assets: `PRL_Idle`, `PRL_Walk`, `PRL_AimFire`, `PRL_Reload`, and `PRL_Takedown`. It runs automatically after Unity Editor initialization and before a build, and also exposes a menu command.
- Runtime GLB loader normalizes the top-level character rig node to `RigRoot` so shared animation paths work consistently across all 24 unique character models.
- Runtime material creation now loads authored texture sets from `Resources`, assigns base-color, normal and metallic/AO/smoothness maps when the active shader exposes those properties.
- Editor menu validation checks that the five clips and eight complete PBR sets can be loaded through `Resources`.

## Validation scope

The 24 unique character GLBs were inspected at the glTF JSON level: each has a top-level `chr_*` rig node with children and bone nodes named Hips, Spine, Chest, Neck, Head, UpperArmL/R, LowerArmL/R, HandL/R, UpperLegL/R and LowerLegL/R. The loader normalizes the top-level node to `RigRoot`, matching the generated animation curve paths.

The texture PNGs are actual included image files. The `.anim` assets are generated by Unity Editor automation on project open/build; this environment has no Unity Editor, so their Unity serialization, visual pose quality, shader import and runtime playback have not been executed here. Run **Real Loser → Art Pipeline → Generate Authored Character Clips and Configure Textures**, then **Validate Authored Clips and Texture Sets**, and test representative characters in Play Mode before release.

These are original keyframed procedural-authored animation clips, not motion-capture recordings. They provide baseline locomotion and combat posing; they do not yet provide bespoke cinematic animation per character archetype.
